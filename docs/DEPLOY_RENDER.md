# Deploy via Render free plan

Use the Render connector or Render dashboard and authorize the GitHub repository `Ver-Dikt/Bets`. Deploy the Blueprint described in `render.yaml` or configure a Node web service with `npm install` as build command and `node src/server.mjs` as start command.

Hosting is NOT live until Render confirms successful deployment and provides its URL. The free web instance may spin down when idle; provider plan limits apply. The live API uses best-effort third-party sources and may return honest 502 errors. There is no verified continuous live CS2/Dota feed in this version. Do not use the browser-only paper journal as an immutable record. It does not sync across devices.
